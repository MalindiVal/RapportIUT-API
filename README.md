# RapportIUT

Une application web réalisée en HTML/CSS/JS connecté à une API ASP.NET

Lien vers le client : https://github.com/MalindiVal/RapportIUT-Client

## Strucure du projet

L'API est réaliseé en ASP.NET avec une base de donnée en SQLite

### Les controllers

- RapportController
- TagController
- UserController

### Les Services

- RapportService
- TagService
- UserService
- JWTService
